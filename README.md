# Hur att starta projektet

1. installera [Node.js v24](https://nodejs.org/en/download)

2. clona repot
´´´bash
git clone https://github.com/0xNulled/webinlamning-web
´´´

3. Hoppa in i repo mappen
```bash
cd webinlamning-web
```

4. Installera npm paketet & dependencies
```bash
npm install
```

5. Starta hemsidan
```bash
npm run dev
```

6. Gör alla steg i README'n på backend projektet
https://github.com/0xNulled/webinlamning-ASPNET 

7. Besök hemsidan (borde vara på port 5173)
